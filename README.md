## Overview

This repository is based on the commercial Metronic 8 React template and was used to explore dashboard layouts, authentication screens, charts, tables, forms, internationalisation, and right-to-left styling. It is an integration sandbox, not an original design-system release.

## What it does

| Area | Details |
| --- | --- |
| **Dashboard evaluation** | Tests a large collection of dashboard pages and UI components. |
| **Application integration** | Includes routing, authentication, data display, notifications, and client-side service packages. |
| **Theme tooling** | Sass, Bootstrap, Ant Design, Material UI, charts, and RTL build support. |
| **Project history** | The original README identified this workspace with the movie-ticket project iteration. |

## Repository map

| Path | Purpose |
| --- | --- |
| `src/` | React pages, layouts, modules, components, and integrations. |
| `public/media/` | Template artwork, icons, illustrations, and sample assets. |
| `rtl.config.js` | Right-to-left stylesheet build. |
| `serve.js` | Local production-build server. |
